# Instruções para quem edita esta documentação

- Site Mintlify da API de dados da Ziala. Páginas em MDX com frontmatter; menu em `docs.json`.
- Público: equipes de dados dos clientes (Power BI, Airbyte, plataformas como Nekt).
- Português do Brasil, acentuado, voz ativa, "você". Sem travessão longo (—, –): use
  dois-pontos, vírgula ou ponto.
- O nome se escreve **Ziala**, com Z maiúsculo.
- A referência de endpoints vem do OpenAPI publicado pela API. Mudança de campo ou de
  endpoint nasce no código da API; aqui só se explica.
- Repositório público: nada de chave, token, dado real de cliente ou código do produto.
- Exemplos sempre com dados inventados.
