title: 'API de dados'
description: 'Leve os dados da sua conta para o seu painel ou plataforma de dados.'
---

A API de dados entrega, só para leitura, os dados da sua conta na Ziala: contatos,
campos dos contatos, conversas (com a origem do anúncio e o tempo da primeira
resposta), mudanças de etapa e exclusões. É o caminho para montar painéis no Power BI,
no Looker ou na sua plataforma de dados, sem pedir nada à equipe da Ziala.

## Como começar

1. **Ligue a API de dados** em Integrações, no painel da Ziala (só administradores).
2. **Crie uma chave** na mesma tela. Ela aparece uma única vez: copie e guarde no
   sistema que vai ler os dados.
3. **Faça a primeira chamada:**

```bash
curl https://api.ziala.com.br/v1/me \
  -H "Authorization: Bearer $ZIALA_API_KEY"
```

A resposta traz o nome da conta e os limites do seu plano.
