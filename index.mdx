A API de dados expõe os contatos, os campos personalizados, as conversas, o histórico de
etapas e as exclusões da sua conta. Ela foi desenhada para sincronização: paginação por
cursor, leitura incremental e um endpoint de exclusões para manter a sua cópia fiel.

<Note>Disponível nos planos Pro e Enterprise. A API é somente leitura.</Note>

## URL base

```
https://api.ziala.com.br/v1
```

Todas as requisições usam HTTPS, recebem a chave no cabeçalho `Authorization` e respondem
em JSON.
