Expõe contatos, valores de campos personalizados, conversas, histórico de etapas e
exclusões, com paginação por cursor e leitura incremental. Disponível nos planos Pro e
Enterprise.

## URL base

```
https://api.ziala.com.br/v1
```

## Primeira requisição

A chave é criada no painel da Ziala, em **Integrações > API de dados**, por um
administrador da conta.

```bash
curl https://api.ziala.com.br/v1/me \
  -H "Authorization: Bearer $ZIALA_API_KEY"
```

```json
{
  "account_name": "Exemplo Ltda",
  "scopes": ["data:read"],
  "limits": { "per_minute": 60, "per_day": 10000 }
}
```
