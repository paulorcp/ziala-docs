Crie um conector no **Connector Builder** com a configuração abaixo.

## Configuração global

| Opção | Valor |
| --- | --- |
| API Base URL | `https://api.ziala.com.br/v1` |
| Authentication | Bearer Token, com a chave da API |

## Streams

Crie um stream para cada endpoint: `contacts`, `contact_fields`, `conversations`,
`stage_events`, `pipeline_stages`, `fields` e `deletions`.

| Opção | Valor |
| --- | --- |
| Record Selector | `data` |
| Primary Key | `id` (em `contact_fields`, a chave composta `contact_id` + `field_key`) |
| Pagination | Cursor Pagination |
| Next page cursor | `{{ response.next_cursor }}` |
| Stop condition | `{{ not response.has_more }}` |
| Inject cursor into | Parâmetro de query `cursor` |

## Sincronização incremental

Ative **Incremental Sync** nos streams `contacts`, `contact_fields`, `conversations`,
`stage_events` e `deletions`:

| Opção | `contacts`, `contact_fields`, `conversations` | `stage_events` | `deletions` |
| --- | --- | --- | --- |
| Cursor field | `updated_at` | `created_at` | `deleted_at` |
| Inject start time into | `updated_since` | `created_since` | `deleted_since` |
| Datetime format | `%Y-%m-%dT%H:%M:%S.%fZ` | igual | igual |

A API devolve datas com milissegundos e aceita o formato com microssegundos que o
Airbyte envia.

No destino, use o modo **Incremental | Append + Deduped**. Ele grava pela chave primária
e absorve os registros repetidos pelo recuo de 5 minutos.

`pipeline_stages` e `fields` são tabelas de referência pequenas: use **Full Refresh |
Overwrite**.
