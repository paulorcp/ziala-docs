---
title: 'Power BI'
description: 'Ler a API de dados no Power Query, com paginação.'
---

No Power BI Desktop, **Obter dados > Consulta em branco > Editor avançado**, e cole (troque
`contacts` pelo endpoint que quiser):

```
let
    Chave = "zk_live_...",
    Base = "https://api.ziala.com.br/v1/",
    Pagina = (cursor as nullable text) =>
        Json.Document(
            Web.Contents(
                Base,
                [
                    RelativePath = "contacts",
                    Query = if cursor = null then [limit = "200"] else [limit = "200", cursor = cursor],
                    Headers = [Authorization = "Bearer " & Chave]
                ]
            )
        ),
    Paginas = List.Generate(
        () => Pagina(null),
        each _ <> null,
        each if _[has_more] then Pagina(_[next_cursor]) else null
    ),
    Linhas = List.Combine(List.Transform(Paginas, each _[data])),
    Tabela = Table.FromRecords(Linhas)
in
    Tabela
```

- Em **Fonte de dados**, deixe a autenticação como anônima: a chave já vai no
  cabeçalho. Não publique o arquivo com a chave para pessoas que não devem lê-la.
- Para contas grandes, use a **atualização incremental** do Power BI com o filtro de
  data ligado a `updated_since`, e marque `id` como chave.
