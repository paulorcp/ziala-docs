---
title: 'Paginação'
description: 'Paginação por cursor em todos os endpoints de lista.'
---

```json
{
  "data": [],
  "next_cursor": "eyJ0Ijoi…",
  "has_more": true,
  "sync_watermark": "2026-10-13T14:29:00.000Z"
}
```

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| `limit` | integer | 1 a 200. Padrão 100. |
| `cursor` | string | `next_cursor` da página anterior. |

- Ordem fixa pela coluna de data do endpoint e, em empate, pelo `id`, crescente.
  Parâmetros de ordenação são ignorados.
- O cursor é opaco. Mantenha os mesmos filtros entre páginas. Cursor alterado ou de outra
  conta: `400`.
- Resposta limitada a 2 MB: a página pode vir com menos itens que o `limit`.
- `next_cursor` é `null` e `has_more` é `false` na última página.
