---
title: 'Erros'
description: 'Formato RFC 9457 e códigos de status.'
---

Erros seguem a [RFC 9457](https://www.rfc-editor.org/rfc/rfc9457), com
`Content-Type: application/problem+json`.

```json
{
  "type": "about:blank",
  "title": "Requisição inválida",
  "status": 400,
  "detail": "limit deve ser um número inteiro de 1 a 200.",
  "request_id": "req-3f2a"
}
```

`title` é fixo por status. `detail` descreve a ocorrência e pode mudar de texto.
`request_id` identifica a requisição para o suporte.

| Status | Significado |
| --- | --- |
| `400` | Parâmetro ou cursor inválido. |
| `401` | Chave ausente, inválida ou revogada. |
| `403` | API de dados desligada na conta, ou plano sem acesso. |
| `404` | Registro não encontrado nesta conta. |
| `429` | Limite de requisições atingido. |
| `500` | Erro inesperado. |
| `503` | Serviço temporariamente indisponível. |

Todas as operações são de leitura: repetir uma requisição é sempre seguro.
