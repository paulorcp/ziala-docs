---
title: 'Autenticação'
description: 'Chave de API por conta, enviada como token Bearer.'
---

```
Authorization: Bearer zk_live_<id>_<segredo>
```

- A chave pertence a uma conta e só lê os dados dela. Escopo único: `data:read`.
- Até 5 chaves ativas por conta.
- A chave é exibida só na criação. A Ziala armazena apenas o hash.
- Chave ausente, inválida ou revogada: `401`. A revogação tem efeito imediato.
- API de dados desligada na conta: `403` para todas as chaves.
- Não envie a chave em parâmetro de URL.
